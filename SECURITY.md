# Security

## Sensitive local data

DLB Browser stores browser profiles outside the repository in the application user-data directory. Never attach that directory to a GitHub issue or commit it to source control. It may contain cookies, local storage, IndexedDB data, proxy credentials and generated Xray configuration files.

## Reporting

Before reporting a problem, remove account names, email addresses, proxy hosts, VLESS links, UUIDs, cookies, tokens and screenshots containing private account data.

## 中文

账号数据保存在仓库外的应用数据目录，不应上传到 GitHub。分享诊断信息前，请移除账号、邮箱、代理链接、访问密钥、个人备注及含个人信息的截图。
